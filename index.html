ansible-offline-install内网没外网，也能一键装好 Ansible

把 Ansible 打成一个离线安装包：拷到内网机器上，运行一条命令就装好，全程不需要网络。

快速开始
下载离线包
GitHub 主仓库
📴

全程离线

安装时 pip 走本地 wheelhouse 并带 --no-index，不访问任何网络。气隙环境、机房内网都能装。

🖥️

8 个平台组合

EL 9 系列 / Ubuntu 24.04 / Ubuntu 22.04 / Debian 12，x86_64 与 ARM64 各一份，全部由 CI 在真实机器上构建并完成安装测试。

🛡️

不动系统环境

Ansible 装进独立的 venv 文件夹（root 在 /opt/ansible-offline，普通用户在 ~/ansible-offline），删掉文件夹即卸载干净，不影响系统 Python。

📌

版本锁定可复现

requirements.txt 锁定 ansible-core==2.18.19，每台机器装出来的环境完全一致。

🧩

collections 随包自带

离线包默认附带 ansible.posix 与 community.general 两个最常用的 collection 及其依赖，装好即用。

🌏

双语脚本

安装与打包脚本默认中文，--lang en 或 ANSIBLE_OFFLINE_LANG=en 切换英文；本文档站同样提供中英文。

60 秒上手 ​

bash
# 1. 解压（先按平台矩阵选对包，再从下载页拿校验文件验一下）
tar xf ansible-offline-install-2.0.0-el9-x86_64-py311.tar.gz
cd ansible-offline-install-2.0.0-bundle

# 2. 安装，全程离线，装完自动验证
bash install.sh

# 3. 确认
ansible --version
  • 细节看快速开始，选包看平台支持矩阵。

这是干什么的 ​

很多公司、机房的服务器不允许连接外网（俗称「气隙环境」），这时直接在服务器上执行 pip install ansible 一定会失败，因为它要去网上下载。

这个项目的办法很简单，分三步：

  1. 先在一台能上网的电脑上，把安装需要的全部文件打包成一个压缩包（或者直接下载本项目已经打好并测试过的包，见快速开始）；
  2. 把这个包拷进内网（U 盘、跳板机、内网文件服务器，都行）；
  3. 在内网服务器上运行包里的安装脚本，把 Ansible 装进一个独立文件夹，不动系统原有的环境，删掉文件夹就能卸载干净。
