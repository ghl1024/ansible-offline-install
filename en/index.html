ansible-offline-installInstall Ansible with no internet, in one command

Ansible packaged into a single offline bundle - copy it to your air-gapped machine, run one command, done. No network needed during installation.

Quick Start
Download a Bundle
GitHub Repository
📴

Fully offline

At install time pip uses a local wheelhouse with --no-index and never touches the network. Works in air-gapped datacenters and intranets.

🖥️

8 platform combinations

EL 9 family / Ubuntu 24.04 / Ubuntu 22.04 / Debian 12, on both x86_64 and ARM64. Every bundle is built and install-tested by CI on real machines.

🛡️

System environment untouched

Ansible goes into a dedicated venv folder (/opt/ansible-offline for root, ~/ansible-offline for regular users). Delete the folder to uninstall completely.

📌

Pinned and reproducible

requirements.txt pins ansible-core==2.18.19, so every machine gets an identical environment.

🧩

Collections bundled

Bundles ship ansible.posix and community.general (with dependencies), the two most commonly used collections, ready to use offline.

🌏

Bilingual scripts and docs

The installer and builder print Chinese by default; --lang en or ANSIBLE_OFFLINE_LANG=en switches to English. This documentation is bilingual too.

Running in 60 seconds ​

bash
# 1. Extract (pick the right bundle in the platform matrix first,
#    and verify it with the .sha256 file from the download page)
tar xf ansible-offline-install-2.0.0-el9-x86_64-py311.tar.gz
cd ansible-offline-install-2.0.0-bundle

# 2. Install - fully offline, self-verifies at the end
bash install.sh

# 3. Confirm
ansible --version

What this does, in plain words ​

Many company and datacenter servers are not allowed to reach the internet (an "air-gapped" environment). On such a machine, pip install ansible always fails, because it needs to download packages.

This project works around that in three steps:

  1. On a computer with internet access, pack everything needed into one archive file (or simply download a ready-made, tested bundle from this project, see Quick Start).
  2. Copy that file into the intranet (USB stick, bastion host, internal file server - anything works).
  3. On the offline server, run the installer inside the bundle. Ansible goes into a dedicated folder, nothing on the system is modified, and deleting that folder uninstalls it completely.
