Releases ​

Current version 2.0.0 (2026-10-27): a ground-up refactor of the installer for current systems. This page is the summary; full notes are in the CHANGELOG and the GitHub Release.

2.0.0 highlights ​

  • Offline installer (install.sh) based on a local wheelhouse and an isolated Python venv; pip runs with --no-index, no network at install time.
  • Bundle builder (scripts/make-offline-bundle.sh) producing a versioned .tar.gz plus a SHA256 checksum for Release distribution.
  • Support matrix: EL 9 family (Rocky / Alma / RHEL / CentOS Stream 9), Ubuntu 24.04 / 22.04, Debian 12 - 8 combinations across x86_64 and ARM64; CI and the release workflow cover the same 8 combinations and build, install-test and publish fully automatically.
  • Ansible pinned to ansible-core==2.18.19, Python >= 3.11 required; both scripts auto-detect a suitable interpreter.
  • Galaxy collections bundled for offline install: ansible.posix and community.general (with dependencies) by default.
  • Scripts print Chinese by default, with --lang en or ANSIBLE_OFFLINE_LANG=en for English; READMEs are bilingual.
  • Published on four platforms: GitHub (primary) plus Gitee / GitCode / CNB mirrors in China, with identical release content (see Download & Verify).

Release assets ​

Every release has 16 assets:

  • Offline bundles for the 8 platform combinations
  • A matching .sha256 checksum file for each

Roadmap (completed) ​

  • Galaxy collections bundled for offline install
  • CI: script checks + install tests for 8 OS/arch combinations
  • Release bundles for x86_64 and ARM64, built, install-tested and published by GitHub Actions on native ARM64 runners
  • This documentation site (private source repository; only the built output is published to the primary repository's GitHub Pages)
