平台支持矩阵 ​

这里的系统指要安装 Ansible 的那台机器（业内叫「控制节点」）。被管理的目标节点不需要任何准备，只要有 SSH 和任意版本的 Python。

支持的系统与 Python ​

系统Python
EL 9 系列：Rocky Linux 9 / AlmaLinux 9 / RHEL 9 / CentOS Stream 93.11（python3.11 包）
Ubuntu 24.043.12（系统自带）
Ubuntu 22.043.11（系统源自带）
Debian 123.11（系统自带）

8 个离线包组合 ​

四个系统 × 两种 CPU 架构，Release 里都有现成包，全部由 GitHub Actions 在真实机器（包括原生 ARM64）上自动构建并完成安装测试：

你的服务器下载这个包
Rocky / Alma / RHEL / CentOS Stream 9，x86_64ansible-offline-install-2.0.0-el9-x86_64-py311.tar.gz
Rocky / Alma / RHEL / CentOS Stream 9，ARM64ansible-offline-install-2.0.0-el9-aarch64-py311.tar.gz
Ubuntu 24.04，x86_64ansible-offline-install-2.0.0-ubuntu2404-x86_64-py312.tar.gz
Ubuntu 24.04，ARM64ansible-offline-install-2.0.0-ubuntu2404-aarch64-py312.tar.gz
Ubuntu 22.04，x86_64ansible-offline-install-2.0.0-ubuntu2204-x86_64-py311.tar.gz
Ubuntu 22.04，ARM64ansible-offline-install-2.0.0-ubuntu2204-aarch64-py311.tar.gz

  • 文件名每一段都有含义：
ansible-offline-install-2.0.0-el9-aarch64-py311.tar.gz
└────────────┬───────────┘ └┬┘ └─┬───┘ └──┬──┘
          版本 2.0.0       系统   架构    Python 版本

🧭 选包口诀：uname -m 显示 x86_64 就选 x86_64 包；显示 aarch64 就是 ARM64，选 aarch64 包。

版本锁定 ​

📌 requirements.txt 锁定了 ansible-core==2.18.19（最后一个支持 Python 3.11 的 2.18 系列版本），保证每台机器装出来的环境完全一致、可复现。

不支持的系统 ​

⚠️ CentOS 7 不能用：它已在 2024 年停止维护，自带的 Python 版本也太老，新版 Ansible 装不上。请换成 EL 9 系列（如 Rocky Linux 9）。
