自制离线包 ​

绝大多数人不需要自己打包：现成包已经覆盖 4 个系统 × 2 种架构（见平台支持矩阵），直接下载即可。只有下面两种情况才需要自己打包：

  • 想换 Ansible 版本；
  • 想增减随包附带的 collections。

打包步骤 ​

  1. 准备一台打包机，它必须同时满足：

    • 能上网
    • 系统 / CPU 架构 / Python 版本与离线机一致

  2. 克隆主仓库后运行打包脚本：

bash
bash scripts/make-offline-bundle.sh
  1. 产物在仓库的 dist/ 目录下：ansible-offline-install-2.0.0-bundle.tar.gz 和它的 .sha256 校验文件。拷到离线机上按快速开始的第二、三步操作即可。

🌏 脚本默认中文，bash scripts/make-offline-bundle.sh --lang en 或环境变量 ANSIBLE_OFFLINE_LANG=en 可切英文。

可选项（环境变量） ​

环境变量作用
WITH_COLLECTIONS=0只打包 Ansible 本体，不带 collections，包更小
PYTHON_BIN=python3.11指定用哪个 Python 打包（系统里有多个 Python 时）；不指定时脚本会自动探测 python3.13 / 3.12 / 3.11 中第一个满足 >= 3.11 的解释器
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple海外网络不通时给 pip 换国内源（示例为清华源，也可换阿里云源）

另外，想换 Ansible 版本：改 requirements.txt 里 ansible-core 的版本号再打包。

随包 collections ​

  • 从 Releases 下载的离线包里已经包含 ansible.posix 和 community.general（含它们的依赖），运行 install.sh 时会自动装好，无需任何额外操作。
  • collections-requirements.yml 记录了清单细节；想增减 collection 名单，改这个文件后重新打包即可。
  • 安装时不想装 collections：INSTALL_COLLECTIONS=0 bash install.sh。

注意：collections 的来源

collections 是从海外的 Ansible Galaxy 下载的，国内没有稳定镜像。打包机连不通 Galaxy 时，这一步会失败；这种情况请直接用 Releases 里的现成包，现成包里已经包含 collections。
